# Организация чатов и обслуживание портала

Обновлено: 14.10.2026. Для всех чатов проекта. Цель — убрать путаницу между чатами и упорядочить работу над порталом «Я выбираю свою траекторию».

## 1. Принципы
- Один чат — одна зона ответственности: чат меняет только свои файлы.
- Любой новый чат начинается с чтения «Карта проекта и сводка по чатам.md» (лежит в корне рабочей папки).
- Результат работы — всегда в файл проекта, а не только в чат.
- Все правки — только в папке с двойным Desktop: `C:\Users\Lotmel\Desktop\Desktop\ИОП старшеклассников`.
- Завершая сессию, чат оставляет короткий итог по шаблону (см. п. 4).

## 2. Карта чатов (рекомендуемая структура)
1. **Координация проекта** (главный чат) — ведёт карту проекта, реестр задач, принимает итоги других чатов и ставит задачи. Контент сам не правит.
2. **Портал: разработка и настройка** — «Я выбираю свою траекторию.html» (единый файл, он же веб-версия): роли, тексты занятий, вход и регистрация, стили, исправление шероховатостей, коммит и пуш.
3. **Методички и материалы к занятиям** — 20 методичек, бланки, интерактивы, «Библиотека источников тьютора», ссылки внутри них (../../ и ../).
4. **Исследования и отчёты** — 13 отчётов, «Реестр источников и ссылок», новые исследования.
5. **Запуск центра** — «Экспертиза концепции…», «Оптимизация запуска…», «Система запуска и внедрения предложений»: реестр 32 предложений, паспорта инициатив, волны, KPI.

Правило: не смешивать портал с отчётами в одном чате; правки чужой зоны согласуются через координационный чат.

## 3. Что делать в каждом чате
- Старт любой сессии: «Прочитай “Карту проекта и сводку по чатам.md”. Зона: <зона>. Задача: <задача>».
- **Чат портала — чек-лист изменения:** 1) правка в «Я выбираю свою траекторию.html» (единый файл — рабочий и веб-версия); 2) проверка: вход школьника 8–9, школьника 10–11 (тексты ЕГЭ) и тьютора, скрытие блоков, печать документа, ссылки; 3) git commit и push; 4) отметка в карте проекта.
- **Чат методичек:** ссылки должны вести на существующий «Я выбираю свою траекторию.html» (../../ из «Методички HTML», ../ из «Библиотеки»); после перегенерации из скриптов (папка «Методички\Вспомогательные материалы\Скрипты сборки») — проверка рендера.
- **Чат отчётов:** новые источники — в «Реестр источников и ссылок»; проверка, что ссылки открываются из РФ без VPN.
- **Чат запуска:** реестр предложений и статусы, фиксация решений руководителя.

## 4. Шаблон итога (передача дел)
В конце сессии в координационный чат передаётся: Изменённые файлы: …; Что проверено: …; Что осталось: …; Нужно обновить карту: да/нет.

## 5. Как координация получает информацию
Прямого канала «чат ↔ чат» нет — мост работает через общие для всех чатов носители. Три канала:
1. **Файлы проекта** (основной, pull): результаты каждой сессии сохраняются в файлы; координация читает их, когда нужна деталь.
2. **Память проекта** (автоматический, push): рабочий чат сохраняет 1–2 заметки за сессию — они сами подгружаются в новые сессии проекта, включая координационную.
3. **Карта проекта и git**: в конце сессии чат дописывает строку в «Хронологию» карты; история git показывает правки файлов, даже если отчёт забыт.

Порядок работы:
- Рабочий чат в конце сессии: сохранил файлы → строка в карту → заметка в память («Сделано / Решение / Осталось»).
- Координационный чат в начале сессии: читает карту и свежие заметки памяти, при необходимости сверяет даты файлов и коммиты, ставит задачи.
- Если сессия оборвалась: в координационном чате попросить «посмотри, что изменилось за последние дни» — найдёт по датам файлов и коммитам.
- Карту в один момент времени правит только один чат: завершающий сессию либо координация.

## 6. Бэклог портала (ближайшие задачи)
- Синхронизировать веб-версию и запушить (правки от 14.10 ждут).
- Вход в существующий аккаунт (сейчас только регистрация; после очистки браузера профиль недоступен).
- Согласовать классы: заголовок обещает 7–11, регистрация — 8–11; у 10–11 те же этапы с метками 8-1/8-2.
- Исправить шероховатости: дубликат class у кнопок «Бланк», лишний «>», сбитая нумерация комментариев; добавить ссылку на методичку занятия 8-1.
- Выбрать финальный вариант входа из «Варианты входа с новыми ролями.html».
- Добавить экспорт/импорт резервной копии данных (сейчас только .txt по одному документу).
- Надёжность: не хранить пароли открытым текстом (есть готовая hash()), аккуратная замена «ОГЭ→ЕГЭ».

## 7. Среда и договорённости
- Чаты открывать только в папке двойного Desktop; одинарный Desktop — устаревший снимок, не использовать.
- Имена файлов — по-русски, без дефисов и подчёркиваний; ссылки проверять без VPN.
- Ритм: раз в неделю координационный чат обновляет карту и статусы; после крупных правок портала — сразу синхронизация и пуш.
