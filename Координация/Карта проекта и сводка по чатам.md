# Карта проекта и сводка по чатам

Обновлено: 14.10.2026. Точка входа для новых чатов: суть проекта, где что лежит, что уже сделано и что делать дальше.

## 1. О проекте
Индивидуальное сопровождение одарённых старшеклассников (ИОП, ИУП, ИОМ) и запуск центра персонализированного обучения: воронка отбора, тьюторское сопровождение, курс занятий для 8–9 классов, интерактивный портал для школьников и наставников.

## 2. Рабочая папка и правила
- Все правки — только в папке с ДВОЙНЫМ Desktop: `C:\Users\Lotmel\Desktop\Desktop\ИОП старшеклассников`.
- `C:\Users\Lotmel\Desktop\ИОП старшеклассников` (одинарный Desktop) — устаревший частичный снимок (до 01.10.2026): без портала, git и «Методичек». Не редактировать.
- В корне лежит только портал (рабочий файл и веб-копия) и технические index.html, .gitignore. Всё остальное — в папках зон (см. п. 7 «Структура папок»).
- Все чаты проекта работают в этом каталоге и сохраняют результаты в файлы своих зон.
- Правила распределения работ между чатами — «Организация чатов и обслуживание портала.md» (папка «Координация»).
- Текущие задачи по зонам — «Реестр задач по зонам.md» (папка «Координация»).
- Имена файлов — по-русски, без дефисов и подчёркиваний между словами; ссылки проверять (открываются из РФ без VPN).
- Git в папке проекта → GitHub Lotmel2015/navigator-centra → сайт https://lotmel2015.github.io/navigator-centra/. Коммит и пуш — git из папки проекта.

## 5. Ключевые выводы исследований
- Главный фактор эффекта — живой тьютор или наставник; платформа масштабирует его дёшево (ИИ без вовлечения прироста не даёт).
- Главная незанятая ниша в РФ — измерение результата: рынок меряет охват, а не прирост.
- Рекомендация: пилот на 50–300 учеников, SaaS + студенты-тьюторы, с первого дня мерить дозу контакта и входной/выходной тест.
- Прогноз воронки центра: 1200 заявок → 800 диагностик → 450 пар → 300–350 завершивших год. ИУП оформляет школа, центр дополняет треками.

## 6. Возможности деятельности (что делать дальше)
1. Запушить текущий портал «Я выбираю свою траекторию.html» (единый файл вместо «Навигатор центра.html»), коммит и пуш — сайт обновится.
2. Запуск по регламенту: единый реестр 32 предложений со статусами, паспорта инициатив, 3 волны по 2 недели, штаб 15 минут в понедельник.
3. Фаза 0 внедрения: правовая рамка (152-ФЗ, лицензия ДО), KPI-дашборд, тест инструментов на 3 волонтёрах, затем пилот 30–50 учеников.
4. Достройка портала: выбрать финальный вариант входа («Кто ты сегодня» уже реализован в портале), развивать раздел наставника.
5. Поддерживать методички, бланки и библиотеку источников; обновлять этот файл и заметки памяти проекта.

## 7. Структура папок (с 14.10.2026)
```
Корень:
  Я выбираю свою траекторию.html   — единый портал (рабочий файл и веб-версия GitHub Pages)
  index.html, .gitignore           — технические файлы (сайт и git)
```
